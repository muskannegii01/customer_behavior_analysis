# Customer Shopping Behavior Analysis

## Overview
This project analyzes customer shopping behavior using Python, MySQL, and Power BI.

## Tools Used
Python, Pandas, MySQL, SQL, Power BI

## Project Steps
1. Loaded and explored the dataset using Python.
2. Cleaned the data.
3. Stored the data in MySQL.
4. Used SQL queries to analyze customer behavior.
5. Created a Power BI dashboard.

## Dashboard
The dashboard shows customer count, average purchase amount, review ratings, subscription status, revenue by category, and age group analysis.

## Results
Clothing had the highest revenue among the categories shown. Approximately 73% of customers were not subscribed. The average purchase amount was $59.76, and the average review rating was 3.75.

## Conclusion
This project helped me practice data cleaning, SQL analysis, and dashboard creation using Python, MySQL, and Power BI.
